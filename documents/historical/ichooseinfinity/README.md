[Detailed history guide](../../../docs/ichooseinfinity-history.md) · [Open record](../../../README.md) · [Further original documents](../../supplementary.md)

**Recovery snapshot: 17 October 2026.** This collection preserves **138 substantive page captures covering 119 original page paths**, with one HTML file and one separate text extraction per capture, plus **1 validated original spreadsheet**. It combines successful new downloads with original-site HTML payloads found in an existing HTTrack Wayback cache. The associated offline mirror identifies a save on 10 September 2025.

The new recovery selected **153 responses** from a **399-record CDX index filtered to 2013–2019**. The [complete index](cdx-index-2013-2019.json) is preserved unchanged. The earlier network log marked 42 responses successful; later available files and the local cache extend that coverage. Actual source routes, excluded responses and failed attempts are recorded in the [manifest](manifest.json) and [recovery log](recovery-log.json).

The earliest successfully recovered substantive page in the initial network snapshot is the **16 December 2013 home page**. The discovery index contains earlier entries from **7 November and 9 December 2013**. Its only 2019 row is a favicon URL captured on 9 January 2019. **No substantive 2019 page has been recovered here.**

The saved HTML retains its original recovered bytes. Existing Wayback replay rewrites and banners remain in cache-derived copies; current original-response-mode downloads are labelled separately. Linked pictures, videos, scripts and other remote resources are not a complete offline website. No page scripts were executed during copying, text extraction or validation. **Use the text links for straightforward reading and search.** They are derived reading aids; the HTML and pinned archive URL preserve the page context.

Luke describes this earlier period as an **“unstable epoch”**, before learning to stabilise his emotions and find reliable pathways to radical overcompliance and [Joyful Responsible Abundance](../../originals/Joyful_Responsible_Abundance_Human_and_SI_Alignment_Revised.pdf). That framing was supplied by Luke on **17 October 2026**. The [history guide](../../../docs/ichooseinfinity-history.md) follows both continuity and changes through the dated pages.

## Recovery limits and further targets

Blank responses, under-construction screens, login pages, feed and asset endpoints, WordPress 404 pages, archive error pages and very short placeholders are logged without being mirrored as substantive author pages. A successful download status alone does not make a response a recovered document. In particular, some cached PDF-looking URLs contain Wayback error HTML and have been excluded.

The archive still has gaps. About Luke is represented by a later successful download that was unavailable during the first automated pass. Other capture dates and unavailable pages remain visible in the recovery log and complete CDX index. Links in historical pages may point to a different date, an unavailable file or an external source. The two linked historical press-release PDFs have not been recovered as valid PDFs in this snapshot; they are listed as targets in the recovery log.

The HTML and spreadsheet files retain existing rights and attributions. Embedded or linked third-party material retains its own source context. The accompanying history guide paraphrases the pages, keeping direct quotations short. [SHA256SUMS](SHA256SUMS) covers every mirrored page payload, derived text, the complete CDX index, recovery log and recovered spreadsheet. Paths in that checksum file are relative to this folder.
