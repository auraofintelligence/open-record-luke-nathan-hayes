## Published text and track order

The first two collections follow the album track lists and lyric bodies in the [Music Universe catalogue at revision 14baf99](https://github.com/auraofintelligence/i-C-infinity-music-universe/blob/14baf99ddbc1fad52eaebaabc4e78f896b979293/data/catalogue.json). Wording, spelling, punctuation and section labels are retained. The PDF editions add line wrapping, typography, page breaks and navigation. Their readable text companions preserve each published lyric body in a separate text block.

The title track of [Chronicles of the Forgotten](https://auraofintelligence.github.io/i-C-infinity-music-universe/albums/chronicles-of-the-forgotten/) occupies both [position 1](https://auraofintelligence.github.io/i-C-infinity-music-universe/songs/chronicles-of-the-forgotten-01-chronicles-of-the-forgotten/) and [position 16](https://auraofintelligence.github.io/i-C-infinity-music-universe/songs/chronicles-of-the-forgotten-16-chronicles-of-the-forgotten/) in that source. Both positions remain in the collected edition.

## Source record

The [preserved catalogue snapshot](sources/music-universe-catalogue-2026-10-19.json) is the exact source file used for the first two collections. The [manifest](manifest.json) records the pinned source revision, each track's source note and lyric checksum, PDF page positions and file checksums. The [checksum list](SHA256SUMS) covers the source snapshot, reading editions, readable text, manifest and supplied third-album file.
